# Privacy and safety model

This repo is safe to review publicly only after Boris confirms the final GitHub visibility.

Publication checklist:

- Synthetic hosts only.
- Synthetic command outputs only.
- No real emails, phone numbers, Telegram group names, Gmail snippets, external profile private URLs, tracker IDs, CV content, browser profile paths, or tokens.
- No `.env`, cookies, credentials, or private Hermes configuration.
- No claims of production deployment.
- README uses "lab", "demo", "prototype", and "portfolio-safe" wording.
